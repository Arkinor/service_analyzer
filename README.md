# Анализатор служб Windows

Программа показывает все службы и (по желанию) драйверы Windows и объясняет,
какие из них выглядят безопасно, а какие стоит проверить: подпись, издатель,
расположение файла, настройки, поведение и признаки майнеров.

Это **не антивирус**. «Безопасно» означает «не найдено известных признаков
проблемы», а не абсолютную гарантию чистоты файла. Зато у каждого вердикта
видно, из чего он сложился.

## Возможности

- **Проверка Authenticode**: действительна ли подпись, кто издатель, не изменён
  ли файл после подписи, доверенный ли сертификат.
- **Проверка ServiceDll**: службы внутри общего `svchost.exe` проверяются по их
  библиотеке, а не по подписанному самой Microsoft оболочке `svchost.exe`.
- **Расположение файла**: System32, Program Files, ProgramData, AppData, Temp,
  загрузки, сетевой путь, съёмный диск.
- **Настройки службы**: учётная запись, незакавыченный путь, запуск через
  PowerShell/cmd/rundll32, скрипт вместо программы, двойные расширения,
  маскировка имени под системное.
- **Свойства файла**: компания, версия, дата создания, размер, SHA-256.
- **Поведение**: загрузка ЦП, память, родительский процесс, сетевые соединения
  (для служб в собственном процессе).
- **Признаки майнеров**: XMRig/NBMiner и т.п., параметры stratum, адреса пулов,
  криптокошельки, порты пулов, высокая нагрузка ЦП.
- **Глубокий анализ прав**: может ли обычный пользователь записать файл в папку
  службы, работающей от SYSTEM (риск подмены).
- **Фильтры и сортировка**, понятная панель объяснений, экспорт в HTML/CSV/JSON.
- **VirusTotal по желанию**: отправляется только SHA-256, сам файл не загружается.
- **Русский интерфейс** и отчёт с пояснениями.

## Запуск из исходников

Требуется Windows и Python 3.11.

```bat
setup.bat
.venv\Scripts\python.exe service_analyzer.py
```

Для полного доступа к защищённым файлам и сетевым данным запускайте от имени
администратора. Программа предупредит, если прав недостаточно.

Полезные ключи:

```bat
.venv\Scripts\python.exe service_analyzer.py --no-scan
```

`--no-scan` открывает окно без автоматического сканирования.

## Сборка exe

```bat
build.bat
```

Готовый файл: `dist\service_analyzer.exe`. Сборка использует PyInstaller,
`--onefile`, `--noconsole` и `--uac-admin` (запрос прав администратора при
запуске).

## Как читать уровни

| Уровень | Значение | Что делать |
|---|---|---|
| ⛔ **Опасно** | Сильные признаки: подмена подписи, майнер, запуск из Temp/AppData, высокая нагрузка у неподписанной службы | Не запускать, проверить хэш в VirusTotal, полная проверка антивирусом |
| ▲ **Подозрительно** | Нетипичные признаки: нет подписи и странная папка, слабые права на папку, маскировка имени | Проверить издателя, папку, хэш; при сомнениях отключить |
| ? **Проверить** | Скорее нормально, но подпись или место нетипичны | Посмотреть издателя и дату файла |
| ✔ **Безопасно** | Действительная подпись, ожидаемое место, нет странного поведения | Действий не требуется |

Баллы — это сумма весов найденных признаков, а не «магическая» цифра. В панели
справа перечислены все причины с пояснениями и советами.

## Что означают кнопки

- **Сканировать** — полный проход. Настройки сканирования находятся над таблицей:
  - «включая драйверы» — добавить драйверы (клавиатуры, видео, фильтры ФС и т.п.);
  - «проверять нагрузку ЦП и сеть» — снять поведение запущенных служб;
  - «глубоко: права на папки» — проверить ACL папок (медленнее).
- **Экспорт** — HTML-отчёт с объяснениями, CSV для Excel или JSON для автоматизации.
- **Проверить в VirusTotal** — запрос по SHA-256 выбранного файла. Нужен
  бесплатный API-ключ (VirusTotal → профиль → API Key). Ключ хранится локально
  в `%APPDATA%\ServiceAnalyzer\config.json` в открытом виде.
- **Правый клик** — копирование пути/имени/хэша, папка, свойства, VirusTotal,
  поиск, `services.msc`, ключ реестра.

## Ограничения

- Оценка эвристическая: возможны ложные срабатывания и пропуски.
- Некоторые защищённые файлы недоступны без прав администратора.
- Для служб внутри `svchost.exe` нагрузка ЦП и сеть относятся ко всему общему
  процессу, поэтому поведение по ним не оценивается.
- VirusTotal — сторонний сервис; для него нужен интернет и API-ключ.
- Перед отключением службы убедитесь, что она не нужна Windows или вашим
  программам: `sc.exe qc <имя>` покажет конфигурацию.

## Журнал и настройки

- Журнал: `%LOCALAPPDATA%\ServiceAnalyzer\service_analyzer.log`
- Настройки: `%APPDATA%\ServiceAnalyzer\config.json`

## Структура проекта

```
service_analyzer.py      точка входа
analyzer/
  constants.py           справочники, уровни, признаки майнеров
  models.py              структуры данных
  winapi.py              реестр, Authenticode, свойства файлов, ACL, поведение
  collector.py           конвейер сканирования
  rules.py               правила оценки и объяснения
  report.py              экспорт HTML/CSV/JSON
  ui.py                  интерфейс Tkinter
  vt.py                  клиент VirusTotal
  config.py              настройки и пути
  help_text.py           тексты справки
build.bat               сборка exe
service_analyzer.spec   конфигурация PyInstaller
```
